# Native Proxmark3 integration (`pm3-integration`)

## Summary

This branch replaces the **process-wrapper** Proxmark3 path (`proxmark3 -c "..."`) with a **native USB CDC executor** that speaks the Proxmark3 NG/MIX/OLD binary protocol directly over serial. The public `Pm3` API, parsers, session layer, and CLI contracts stay the same — only the executor layer changes.

```
Pm3 / RidesCli / tests
        ↓
   Pm3Session (detect chaining, port discovery, cache)
        ↓
   IPm3CommandExecutor
     ├── Pm3ProcessExecutor   (legacy — spawns proxmark3 client)
     └── Pm3NativeExecutor    (new default — direct binary protocol)
```

**Why:** Faster, more reliable hardware interaction (no process spawn per command), better control over timeouts/buffering, and a foundation for elevator-specific optimizations. The process executor remains available as a fallback for raw CLI passthrough and unsupported tag types.

---

## What’s new

### Native executor (`Pm3NativeExecutor`)
- USB CDC connect, ping, hardware version, LF antenna tuning
- Full T55x7 workflow for elevator tokens: **detect → read → write → dump**
- Synthetic CLI-shaped output via `Pm3NativeOutputBuilder` so existing parsers (`DetectParser`, `BlockReadParser`, `DumpParser`) work unchanged
- Typed command batching (`IPm3DeviceCommand`) instead of raw CLI strings

### Protocol & transport
- NG/MIX/OLD frame codec (`Pm3NgPacketCodec`)
- Persistent serial receive buffer (fixes BigBuf download hang when multiple frames arrive in one read)
- `CMD_CAPABILITIES` on connect — parses firmware v6/v7, uses `bigbuf_size` for sample download sizing, guards T55 ops when LF is not compiled in
- Unix port discovery without requiring a local pm3 install (ioreg + sysfs)

### T55 native service
- LF acquisition + BigBuf download + ASK/Manchester demod (ported/adapted from proxmark3 client logic)
- Detect scans downlink modes; supports elevator config block `0x00148040`
- Write with retry + read-back verify; dump via 8× `READBL` (same as official `lf t55xx dump`, not `resetread`)
- **Detect cache** (30s TTL, test-first policy) — skips redundant detect across batched session commands
- **Unsupported tag handling:**
  - `Pm3UnsupportedModulationException` for known non-ASK T55 variants → hints `PM3_EXECUTOR=process`
  - `Pm3UnsupportedChipTypeException` for alien LF chips (e.g. EM410x misread as FSK)

### Performance improvements
- **Dump tuning:** one transport flush at dump start, skip per-block serial clears, single known-config read per block (no 3× majority loop); RF settle times unchanged
- **LF tune:** optimized sample-count loop, 35-sample default from probe experiments
- **RidesCli:** batched reads of mirror blocks 5+6, `RideBlockResolver` for ride count logic, batched T55 writes for set/reset with persistent detect cache

### Diagnostics & debug
- Temp-file diagnostic logging (`{GetTempPath()}/elevator/`)
- `debug/` tooling relocated: `NativeT55Probe`, benchmarks, LF tune probes, spare-tag experiment scripts
- Offline regression fixtures (captured BigBuf samples) for unit tests without hardware

## Capability matrix

| Capability | Native | Process |
|------------|:------:|:-------:|
| Connect / ping / hw version | ✅ | ✅ |
| LF tune | ✅ | ✅ |
| T55 detect / read / write / dump | ✅ | ✅ |
| Raw CLI passthrough | ❌ | ✅ |
| Non-ASK T55 / alien LF chips | ❌ (clear error + fallback hint) | ✅ |

Native scope is intentionally narrow: **elevator T55x7 tokens, ASK/Manchester, RF/64**.

---

## Configuration & migration

| Setting | Default | Override |
|---------|---------|----------|
| `Pm3Options.ExecutorKind` | `Native` | `PM3_EXECUTOR=process` |
| `RidesCli` / `Pm3Cli` | Native | `PM3_EXECUTOR=process` |
| Device port | Auto-discover | `PM3_DEVICE_PORT` |

No public API breaking changes. Process executor behavior preserved for parity tests and fallback.

## Testing

- **~111 unit tests** (no hardware): codec, demod, capabilities decode, detect cache policy, unsupported modulation/chip type, offline BigBuf fixtures
- **Integration tests** parameterized for `Native` and `Process` executors; native skips only raw CLI passthrough
- **Hardware validated on macOS** (`/dev/cu.usbmodem*`): detect, read, write, dump, cache E2E, capabilities, ASK elevator tag, load tests
- **Linux (`/dev/ttyACM0`)** — deferred (no hardware available)

### Run commands
```bash
# Unit tests
dotnet test --filter "Category!=Integration&Category!=IntegrationParity"

# Integration (hardware)
dotnet test Pm3UsbApi.Tests --filter "Category=Integration" -- NUnit.RunExplicitTests=true
```

- Integration tests use blocks 5/6 with snapshot/restore
- Spare-tag modulation experiments live under `debug/` and use pm3 CLI directly
